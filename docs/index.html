🔔 Vous nous donnez le signal, nous programmons l'évaluation sur Moodle

Chers collègues et responsables de formations, dès qu'un cours est achevé, vous cliquez simplement ici pour le signaler. L'équipe de planification reçoit instantanément la notification pour ouvrir l'évaluation aux étudiants sur Moodle. Si vous le souhaitez, vous pouvez aussi indiquer les dates de début et de fin souhaitées pour la programmation.

Bienvenue sur l'Espace Programmation des Évaluations

Campagne 2026-2027 · Guide rapide pour les collègues & coordonnateurs

Chers collègues, vous n'avez plus besoin de manipuler Moodle ! Dès qu'un cours est achevé dans votre filière, donnez simplement le signal ici. L'équipe de planification s'occupe de l'ouverture et du paramétrage.
1
Sélectionnez votre périmètre

Cliquez sur Licence, Master ou MBA sur la page d'accueil, puis choisissez votre filière dans la liste déroulante.

2
Cochez les cours terminés

Cochez le ou les modules achevés. Le nom de l'enseignant est facultatif. Vous pouvez indiquer vos dates souhaitées d'ouverture et de clôture.

3
Donnez-nous le signal !

Cliquez sur « Envoyer le signal pour programmation ». L'équipe de planification (Oscar Kakpo) est alertée immédiatement sur Outlook et active l'évaluation sur Moodle.
