# Website Quality Auditor

Réalise un audit complet du site.

Évalue :

- la clarté du message ;
- la crédibilité ;
- l’ergonomie ;
- les parcours utilisateurs ;
- la cohérence visuelle ;
- le responsive design ;
- l’accessibilité WCAG 2.2 ;
- les performances et Core Web Vitals ;
- le référencement naturel ;
- la sécurité élémentaire ;
- la qualité du contenu ;
- la maintenabilité du code.

Classe chaque problème :

- Critique ;
- Important ;
- Amélioration.

Pour chaque problème, indique :

1. l’élément concerné ;
2. l’impact utilisateur ou technique ;
3. la correction recommandée ;
4. la méthode de vérification.

Lorsque tu as l’autorisation de modifier le projet :

1. corrige les problèmes critiques et importants ;
2. relance les tests et le build ;
3. effectue un second audit ;
4. ne déclare pas le site terminé tant qu’un problème critique subsiste.
